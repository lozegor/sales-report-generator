# Генератор Excel-отчётов о продажах

Программа объединяет несколько Excel-файлов с продажами, проверяет данные и создаёт готовый отчёт.

## Что создаёт программа

- Общую выручку.
- Лучшего менеджера.
- Выручку и долю каждого менеджера.
- Выручку, количество и долю каждого товара.
- Сводку по исходным Excel-файлам.
- Диаграммы выручки по менеджерам и товарам.
- Лист с объединёнными исходными данными, фильтром и закреплённым заголовком.

## Исходные файлы

Положите Excel-файлы с продажами в папку `input`.

Каждый файл должен содержать столбцы:

```text
Менеджер
Товар
Количество
Цена
```

Количество и цена должны быть положительными числами.

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python3 analysis_commented.py
```

По умолчанию программа создаст файл:

```text
sales_report.xlsx
```

Чтобы задать другое имя готового отчёта:

```bash
python3 analysis_commented.py --output october_report.xlsx
```

Чтобы выбрать другую папку с исходными файлами:

```bash
python3 analysis_commented.py --input другая_папка
```
